# hatch

* [Docs](https://hatch.pypa.io/latest/)
* [GitHub](https://github.com/pypa/hatch)
* [PyPI](https://pypi.org/project/hatch)

Hatch is a unified command-line tool meant to conveniently manage dependencies and environment isolation for Python developers. Python package developers use Hatch and its [build backend](https://packaging.python.org/en/latest/glossary/#term-Build-Backend) Hatchling to configure, version, specify dependencies for, and publish packages to PyPI. Its plugin system allows for easily extending functionality.
Hatch 是一个统一的命令行工具, 旨在方便 Python 开发者管理依赖项和环境隔离. Python 包开发者使用 Hatch 及其[构建后端](https://packaging.python.org/en/latest/glossary/#term-Build-Backend) Hatchling 来配置包、管理版本、指定依赖项并将包发布到 PyPI. 其插件系统可以轻松扩展功能.

```bash
pip install hatch
hatch --version
```
